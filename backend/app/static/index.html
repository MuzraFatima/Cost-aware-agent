Multi-Agent System Pool & Capabilities

CAAR 2.0 maintains a pool of domain-specialized AI agents. The gateway dynamically routes incoming instructions to the most optimal agent based on domain classification, task complexity score, model capacity, and real-time budget pressure.

Global Budget Intelligence Limits

Configure daily and monthly spend limits in USD. When budget pressure score (0–100) crosses 80+, CAAR automatically downgrades model selections to preserve budget.

Manual Confidence Routing Policy Adjustments

Define the minimum confidence criteria that model generations must satisfy before returning to client requests. High values force the router to escalate to more reasoning/expensive tiers.
